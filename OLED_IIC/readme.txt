实验三：0.96 寸 OLED (IIC) + AHT20 温湿度 + 滚动显示
======================================================

一、实验要求
------------
使用 STM32F103 的 SPI 或 IIC 接口实现：
    1. 显示学号 632407030627 和姓名 王兴；
    2. 显示 AHT20 的温度和湿度；
    3. 左右滑动显示长字符串：
       “Hello，欢迎来到重庆交通大学物联网205实训室！”
       并演示 SSD1306 硬件滚动模式。

二、硬件连接
------------
OLED 和 AHT20 共用一条 IIC 总线：

    OLED  VCC -> 3.3V
    OLED  GND -> GND
    OLED  SCL -> PB6
    OLED  SDA -> PB7

    AHT20 VCC -> 3.3V
    AHT20 GND -> GND
    AHT20 SCL -> PB6
    AHT20 SDA -> PB7

    OLED  地址：0x78（7 位地址 0x3C）
    AHT20 地址：0x38（8 位写地址 0x70，读地址 0x71）

如果实际接线不同，修改 Core/Inc/main.h 中的 OLED_SCL_Pin、OLED_SDA_Pin
以及 OLED_GPIO_CLK_ENABLE()。

三、工程结构
------------
    Core/Src/main.c       主程序：界面切换、温湿度显示、滚动显示
    Core/Src/oled.c       SSD1306 驱动：显存、局部刷新、软件/硬件滚动
    Core/Src/oledfont.c   16x16 汉字与 8x16 ASCII 点阵数据
    Core/Src/soft_iic.c   软件 IIC 总线（支持读写和 ACK）
    Core/Src/aht20.c      AHT20 温湿度传感器驱动
    Core/Inc/oled.h       OLED 驱动接口
    Core/Inc/aht20.h      AHT20 接口
    Core/Inc/soft_iic.h   软件 IIC 接口
    Core/Inc/oledfont.h   字库索引
    tools/gen_font.py     字库生成脚本
    tools/preview_screens.py  生成显示效果预览图
    Docs/screens_preview.png  三个界面的效果预览

四、显示界面
------------
程序循环显示三个界面：

1. 学号、姓名 + AHT20 温湿度（约 7 秒，温湿度每秒更新）
      学号632407030627
      姓名王兴 AHT20
      温度:25.3C
      湿度:56.7%

2. 软件滚动（完整长字符串，约 8 秒）
      重庆交通大学
      到重庆交通大学物联网...
      物联网205实训室

3. 硬件滚动（SSD1306 内置滚屏，约 7 秒）
      重庆交通大学
      Hello，欢迎来到
      物联网205实训室

五、汉字点阵编码原理
--------------------
1. 16x16 汉字共 256 个像素，按“纵向取模、字节低位在上”存储：
   - 每列 1 个字节，bit0 对应最上面一行，bit7 对应第 8 行；
   - 前 16 字节保存上半部分（第 0~7 行）；
   - 后 16 字节保存下半部分（第 8~15 行）；
   - 每个汉字固定 32 字节。

2. SSD1306 显存按“页 + 列”组织：128 列 x 8 页，每页 8 行。
   写入一个字节就是写入某一列的 8 个像素，bit0 在上。

3. 显示 16x16 汉字时：
   - 前 16 字节写入 page；
   - 后 16 字节写入 page+1；
   - 列地址从 x 开始连续写 16 列。

4. 8x16 ASCII 同理，每个字符 16 字节，前 8 字节写 page，
   后 8 字节写 page+1。字库覆盖 0x20~0x7E。

5. 字库由 tools/gen_font.py 使用黑体生成，目前包含：
   学 号 姓 名 王 兴 温 度 湿 欢 迎 来 到
   重 庆 交 通 大 物 联 网 实 训 室 ， ！
   如需增加汉字，修改脚本中的 CN_CHARS 后重新运行，并同步修改
   oled.c 中的字形索引定义。

六、AHT20 温湿度
----------------
AHT20 使用标准 IIC 时序：
    1. 上电等待 40 ms，读状态寄存器；
    2. 如果未校准，发送 0xBE 0x08 0x00 初始化；
    3. 发送 0xAC 0x33 0x00 触发测量；
    4. 等待 80 ms；
    5. 读取 6 字节：状态 + 湿度 20 bit + 温度 20 bit。

湿度 = raw / 2^20 * 100 %
温度 = raw / 2^20 * 200 - 50

程序用定点数显示到 0.1 的单位，避免浮点运算和 printf。

七、滚动的两种实现
------------------
1. 软件滚动（显示完整长字符串）
   把字符串表示为“字形序列”（ASCII 字符或汉字索引），逐帧改变 x 偏移，
   清空 page2~page3 后重新绘制，并用 OLED_RefreshPages(2,3) 只刷新
   这两页。这样既能显示超过 128 像素的长字符串，刷新量也小、动画流畅。

2. 硬件滚动（SSD1306 内置滚屏）
   使用 SSD1306 命令：
       0x2E        关闭滚动
       0x27        水平向左滚动（0x26 为向右）
       0x00        虚拟字节
       start page  起始页
       interval    滚动速度（0~7，越小越快）
       end page    结束页
       0x00/0xFF   虚拟字节
       0x2F        开启滚动
   硬件滚动只移动芯片内部 128x64 显存的内容，无法容纳超过 128 像素的
   字符串，因此本工程用它滚动长字符串的开头部分 “Hello，欢迎来到”，
   完整长字符串由软件滚动方式显示。

八、编译与下载
--------------
1. 用 Keil MDK 打开：
       Project/MDK-ARM/OLED_IIC.uvprojx
2. 编译（F7），生成 Output/OLED_IIC.hex；
3. 用 ST-Link 下载到 STM32F103C8T6 最小系统板；
4. 复位后自动循环显示三个界面，PC13 板载 LED 在温湿度界面闪烁。

本工程已在 MDK 5.36 / ARMCC V5.06 update 7 下编译通过：
    0 Error(s), 0 Warning(s)
    Code = 6344 字节, RO-data = 2776 字节

九、注意事项
------------
- 源文件使用 UTF-8 编码。若 Keil 编辑器中中文注释显示乱码，
  可在 Edit -> Configuration -> Editor 中把 Encoding 改为 UTF-8。
- 源程序中的中文显示内容使用字库索引表示，不依赖编译器对中文字符串
  的编码处理，避免 ARMCC 在 GBK 环境下把 UTF-8 字符串截断。
- 如果 OLED 无显示，优先检查：3.3V 供电、SCL/SDA 是否接反、
  模块地址是否为 0x78。
- 如果温度湿度显示 “ERROR”，检查 AHT20 是否接在 PB6/PB7、
  地址是否为 0x70，以及总线上拉电阻是否正常。
- Docs/screens_preview.png 是按实际字库和排版生成的效果图，
  可用于对照检查显示内容。
